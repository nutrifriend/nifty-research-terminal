Market data provider

Provider adapter: Yahoo Finance chart endpoint (unofficial). The endpoint may change, throttle requests or reject browser CORS requests. No proxy is bundled; the app never sends data to a third party other than the selected market-data host.

Custom endpoint contract: GET {base}/{URL-encoded-symbol}?range=5y&interval=1d and JSON response in Yahoo chart format (chart.result[0].timestamp and indicators.quote[0].open/high/low/close/volume). Must permit CORS from this page. A provider adapter can be replaced in app.js without changing analysis functions.
